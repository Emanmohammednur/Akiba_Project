# Week 2 – Theory Answers

### 1. What is the difference between `if`, `elif`, and `else`?

`if`, `elif`, and `else` help a program make decisions. `if` checks the first condition, `elif` checks another condition if the first one is false, and `else` runs when none of the conditions are true.

### 2. What is the difference between `for` and `while` loops?

Both loops are used to repeat code. I use a `for` loop when I know how many times I want to repeat something, while a `while` loop keeps running as long as its condition is true.

### 3. What are comparison and logical operators?

Comparison operators compare values, such as `==`, `!=`, `>`, and `<`. Logical operators like `and`, `or`, and `not` help us combine or reverse conditions.

For example:

```python
age = 20

if age >= 18 and age <= 60:
    print("Allowed")
```

### 4. What is computational thinking, and what are its seven steps?

Computational thinking means understanding a problem and breaking it into smaller steps before coding.

The seven steps are: Understand, Break it Down, Identify Patterns, Design the Logic, Implement, Test, and Improve.

### 5. Why is testing edge cases important?

Testing edge cases helps me make sure my program works with unusual inputs, not just normal ones. For example, I should test zero, negative numbers, and equal values to find possible mistakes.
