## What I Learned

### Task 1 — Student Information System

In this task, I learned how to create a class and initialize object attributes using the `__init__()` method. I practiced creating multiple student objects with different information and using an instance method to display their details. This helped me understand how classes can be used to organize related information and create multiple objects from the same structure.

### Task 2 — Rectangle Calculator

In this task, I practiced creating a `Rectangle` class with length and width attributes. I used methods to calculate the area and perimeter of a rectangle. This helped me understand how objects can store their own values and how methods can perform calculations using instance attributes.

### Task 3 — Student Score Management

In this task, I learned the difference between class attributes and instance attributes. I created a `Student` class with a shared school name and individual student information such as name, score, and department. I also practiced updating one student's score and displaying the updated information. This helped me understand that instance attributes belong to individual objects, while class attributes are shared by instances of the same class.

### Task 4 — Product Information System

In this task, I practiced creating a `Product` class with attributes such as name, price, and quantity. I learned how to use the `__str__()` special method to return a readable description of an object when using `print()`. I also created a `total_value()` method to calculate the total product value by multiplying price by quantity. This helped me understand how special methods and instance methods can make working with objects more organized and readable.

### Task 5 — Bank Account Management

In this task, I practiced creating a `BankAccount` class to simulate basic banking operations. I implemented methods for depositing money, withdrawing money, and displaying the current balance. I also used conditional statements to validate transactions, reject zero or negative amounts, and prevent withdrawals that exceed the available balance. This task helped me understand how objects maintain their own data and how methods can modify that data while applying conditions to handle invalid operations.
